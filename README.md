# Intro to Backend

A Python learning repository with small backend exercises and assignment code. It is organized by assignment rather than packaged as one application.

## Explore the code

- `PA1/`: assignment starter code.
- `BackendOA/`: backend practice exercises.

The code is for learning and experimentation. Read the assignment or file comments for the task each script is meant to solve.

## Technology

The examples use Python. This repo has no shared dependency file or single framework setup; check the imports in the specific file you want to use.

## Run it yourself

1. Install Python 3.
2. Clone this repository and open it in an editor.
3. Open an exercise and run it from the repository root, for example:

```sh
python3 path/to/script.py
```

If a file imports an additional package, install that package in a virtual environment before running it. Assignment starter code may expect particular inputs or a course-provided environment.

## Demo

This repository contains backend coursework, not a hosted web app, so there is no live service to try. [Browse the source code](https://github.com/Av1Sharma/IntroToBackend) and run an exercise locally using the steps above.
